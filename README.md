# Ganesh Poojari — Asset & Modeling Supervisor Portfolio

Welcome to the personal portfolio website of **Ganesh Poojari**, Asset & Modeling Supervisor with 20+ years of experience in film VFX across top global studios including **Framestore**, **PIXOMONDO**, and **DNEG**.

## 🌟 Features
- **Cinematic Dark & Amber Design System**: High-contrast, glassmorphic UI with double-bezel cards and smooth micro-animations.
- **52 Verified IMDb Production Credits**: Interactive Filmography showcase covering feature films (*Dune*, *Blade Runner 2049*, *The Matrix Resurrections*, *Bohemian Rhapsody*, *Spider-Man: Brand New Day*, *Moana Live-Action*) and TV series (*House of the Dragon*, *Chernobyl*, *Westworld*, *Foundation*, *Dark Crystal*).
- **VFX Showreel Video Modal**: Embedded showreel player with instant preview.
- **ArtStation Background Overlays**: Real 3D sculpts and creature assets directly integrated from Ganesh's ArtStation portfolio.

## 🛠️ Built With
- **Framework**: [Next.js 16](https://nextjs.org/) (App Router & React 19)
- **Styling**: Vanilla CSS & TailwindCSS v4
- **Icons**: [Lucide React](https://lucide.dev/)
- **Deploy**: Vercel / GitHub Pages

## 🚀 Getting Started Locally
Run the development server:
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser.

Build for production:
```bash
npm run build
```
